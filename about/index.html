큐(CUEE)
어르신 기차 예매 길잡이

코레일+ 앱 위에 '다음에 누를 곳' 하나만 비춰, 어르신이 혼자 기차표를 예매하도록 돕습니다.

말 한마디로 조건을 알려 주면, 지금 눌러야 할 버튼에 초록 테두리를 보여 주고 쉬운 말로 소리 내어 알려 드려요.

이렇게 써요

  1. 코레일+ 앱을 엽니다.
  2. 화면 가장자리의 '큐' 버튼을 누릅니다.
  3. "내일 진주에서 서울, 어른 한 명"처럼 말하거나 적습니다.
  4. 초록 테두리가 짚어 주는 곳을 직접 누르며 따라갑니다.

안전 원칙

  • 큐는 대신 누르지 않습니다. 버튼은 사용자가 직접 누릅니다.
  • 로그인, 개인정보, 열차 선택, 예매 확정과 결제는 사용자가 직접 확인하고 진행합니다.
  • 화면 글자와 음성은 저장하거나 보내지 않습니다.

개인정보 처리방침
